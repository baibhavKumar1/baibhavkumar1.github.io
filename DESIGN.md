# DESIGN.md — Staff Fullstack AI Engineer Portfolio (Restrained Editorial Architecture)

## Aesthetic Identity: "Monochrome Precision & Engineering Authority"
A deeply restrained, high-contrast, editorial engineering console built for a Senior/Staff Fullstack AI Engineer. Stripped of all artificial neon gradients, glowing blur blobs, and rainbow category badges. Replaced with pure typographic hierarchy, crisp hairlines, and purposeful single-color accenting.

## Color System (Restrained & Disciplined)
- **Canvas Background**: `#0C0D0E` (Deep Warm Charcoal Ink)
- **Surface Cards**: `#141619` (Elevated Matte Slate)
- **Surface Panel**: `#1A1C20` (High-Contrast Structural Element)
- **Hairline Borders**: `rgba(255, 255, 255, 0.08)` (Crisp 1px Dividers)
- **Primary Text / Headings**: `#FFFFFF` (High-contrast pure white)
- **Secondary Text / Body**: `#8E939E` (Neutral slate grey)
- **Monospace Code / Telemetry**: `#E2E8F0` (High-readability technical data)
- **Single Strategic Accent**: `#38BDF8` (Crisp Ice Blue — reserved strictly for primary interactive focus and live execution indicators)
- **Live Status Only**: `#10B981` (Muted Emerald Dot for production status)

## Design Rules
1. **Zero Rainbow Slop**: No multi-color badges, no glowing gradient text, no floating colored background blur Orbs.
2. **Typographic Rhythm**: Bricolage Grotesque display headings paired with IBM Plex Sans body and JetBrains Mono data tables.
3. **Structured Cards**: Elevated matte `#141619` containers with sharp hairlines, high-contrast white metrics, and clear monochromatic spacing.
4. **Engineering Readability**: Clean monospace output for logs, EDD tabs, and trade-off matrices without distracting multi-color decoration.
